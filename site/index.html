How sure is it?

  • FACT: read directly from Git (this commit exists, this function is defined here).
  • DERIVED: computed from facts (this commit introduced it; it changed 78 times).
  • INFERRED: a heuristic reading (this commit looks like a fix; this workaround may be obsolete).
